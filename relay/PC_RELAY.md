# Ghostly PC Boost

Схема режима:

Телефон → Ghostly VPN → **твой ПК** → интернет → Standoff 2

VPS не нужен. Приложение использует тот же защищённый UDP-протокол Ghostly, а в поле сервера вводится локальный IP ПК.

## Важное ограничение Windows

Чтобы ПК реально принимал IP-пакеты от Android и выпускал их в интернет с NAT, Windows нужен виртуальный сетевой адаптер и права администратора. Обычный Python UDP listener сам по себе не является маршрутизатором.

Поэтому Windows-часть должна использовать системный виртуальный адаптер (например WinTun) и NAT. Я не выдаю «две команды» с обычным UDP-сервером за готовый прозрачный игровой шлюз — это привело бы к неработающему режиму.

## Linux PC

На Linux всё уже использует существующий `relay/relay.py`:

```bash
git clone https://github.com/Selteck1/ApkGhostly.git
cd ApkGhostly
sudo bash relay/install_ubuntu.sh
```

Найди IP ПК:

```bash
hostname -I
```

Токен:

```sudo grep '^GHOSTLY_RELAY_TOKEN=' /etc/ghostly-relay.env```

В Ghostly:
- режим **PC BOOST**
- IP ПК
- UDP 51888
- токен

Телефон и ПК должны иметь сетевую связность.

## Проверка

1. Нажми «Проверить соединение».
2. Нажми «Запустить через ПК».
3. Разреши VPN Android.
4. Standoff 2 запустится автоматически.
5. Остановить всё можно одной кнопкой «Отключить ВСЕ функции».
