# Ghostly Booster / VPS Relay

Ghostly имеет два режима.

## 1. Прямой режим

В этом режиме Ghostly не создает VPN-туннель и не отправляет трафик через сторонний сервер. Standoff 2 использует обычное сетевое подключение Android.

Это самый чистый вариант для сравнения. Он также нужен как базовая точка: сначала измеряем игру напрямую, затем тем же телефоном проверяем VPS.

Важно: Android уже отправляет трафик напрямую, поэтому «прямой режим» не является дополнительным ускорителем сам по себе.

## 2. VPS Relay

Схема:

\`\`\`
Standoff 2
   ↓
Android VpnService
   ↓ UDP + HMAC
Ghostly Relay (VPS)
   ↓ Linux routing/NAT
Интернет / сервер игры
\`\`\`

В VPS-режиме Ghostly разрешает через VPN только пакет:

\`com.axlebolt.standoff2\`

Остальной трафик телефона через relay не отправляется.

## Что нужно

Ubuntu/Debian VPS:
- публичный IPv4;
- открытый UDP-порт 51888;
- root-доступ или sudo;
- желательно VPS с хорошим маршрутом до игровых серверов.

Root нужен только на VPS. На Android root не требуется.

## Установка с ПК

Полная инструкция для Windows/macOS/Linux:

\`relay/PC_SETUP.md\`

После установки у тебя будут:
- IP VPS;
- UDP порт 51888;
- секретный токен.

Их вводишь в приложении Ghostly → \`VPS Relay\`.

## Установка на VPS

Если команда выполняется прямо из клонированного репозитория:

\`\`\`bash
git clone https://github.com/Selteck1/ApkGhostly.git
cd ApkGhostly
sudo bash relay/install_ubuntu.sh
\`\`\`

После установки:

\`\`\`bash
systemctl status ghostly-relay --no-pager
journalctl -u ghostly-relay -n 50 --no-pager
\`\`\`

## Как тестировать

1. В приложении выбери \`Прямой\`.
2. Запусти Standoff 2 и запомни ping/jitter.
3. Выбери \`VPS Relay\`.
4. Введи IP, 51888 и токен.
5. Нажми \`Проверить VPS\`.
6. Нажми \`Запустить через VPS\`.
7. Повтори тот же тест в игре.

Один VPS не гарантирует уменьшение ping. Он полезен только когда маршрут:

\`телефон → VPS → сервер игры\`

лучше, чем:

\`телефон → провайдер → сервер игры\`
