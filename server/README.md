# Ghostly API

Backend для Ghostly APK и чтения публичной статистики Standoff 2.

## Как это работает

```
Ghostly APK
   ↓
Ghostly API
   ↓
Standoff 2 RPC API
```

Приложение не получает пароль пользователя Standoff 2. Для серверного доступа используется отдельный handshake тестового аккаунта.

## Установка в Termux

Из корня репозитория:

```bash
pip install -r server/requirements.txt
```

Затем задайте handshake **локально**, не загружая его в GitHub:

```bash
export STANDOFF2_HANDSHAKE='ВАШ_HANDSHAKE'
```

Запуск:

```bash
bash server/start_server.sh
```

Проверка сервера:

```bash
curl http://127.0.0.1:8081/api/health
```

Проверка игрока:

```bash
curl http://127.0.0.1:8081/api/player/ВАШ_STANDOFF_ID
```

## Важно

AstandyClient — неофициальный клиент Standoff 2. Игровой API может меняться после обновлений игры, поэтому backend должен быть отдельным слоем между APK и игрой.

Handshake имеет ограничения и может становиться недействительным. Для серверного процесса лучше использовать отдельный тестовый аккаунт и не входить этим аккаунтом одновременно в официальный клиент.

Сейчас API читает только данные игрока и не содержит функций изменения аккаунта, рынка или управления игрой.
