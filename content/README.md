# Пакеты контента для Lineup

Папка content/packs хранит пакеты .lineup. Каждый пакет — ZIP с manifest.json и фотографиями. Приложение получает список из catalog.json и проверяет SHA-256 до импорта.

## Публикация обновления
1. В Lineup открой режим администратора и выбери «Экспортировать пакет .lineup».
2. Загрузи/замени файл community.lineup в content/packs через GitHub.
3. Workflow Publish content catalog автоматически обновит content/catalog.json.
4. Пользователи нажимают «Проверить обновления».

Не добавляй пароли, токены и приватные данные. Пакет должен содержать только игровые инструкции и изображения, которые разрешено распространять.
