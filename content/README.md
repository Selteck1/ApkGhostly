# Пакеты контента Lineup

Каждый файл .lineup — ZIP-архив с manifest.json и изображениями. Приложение скачивает его через каталог и проверяет SHA-256.

## Публикация обязательного обновления базы
1. В приложении администратор экспортирует текущую базу в community.lineup.
2. Загружает файл в content/packs/ репозитория, заменяя предыдущую версию.
3. Workflow Publish content catalog автоматически пересчитывает хэш и увеличивает поле revision.
4. После синхронизации новые устройства скачивают этот пакет; существующие устройства блокируют просмотр, пока не загрузят новую ревизию.

Повторный запуск workflow не увеличивает revision, если содержание пакетов не изменилось.
Не добавляй секреты или материалы, права на распространение которых отсутствуют.
