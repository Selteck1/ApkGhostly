# ApkGhostly

Тестовый нативный Android-проект Ghostly.

При запуске APK:
1. открывается полноэкранный режим;
2. проигрывается Ghostly intro ровно 15 секунд;
3. показывается экран готовности:
   - Сервер подключён
   - Соединение установлено
   - Система готова к работе

Текущий статус сервера демонстрационный. После появления backend его можно заменить на настоящий health-check.

GitHub Actions автоматически собирает debug APK при каждом push в main.
