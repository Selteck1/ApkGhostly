# Lineup — офлайн-справочник раскидок Standoff 2

Lineup — Android-приложение для хранения раскидок, тактик, описаний и нескольких фотографий к каждому блоку.

## Обязательная синхронизация базы
- При каждом запуске приложение подключается к каталогу публикаций.
- Если администратор выпустил новую базу, старые данные не открываются, пока актуальный пакет не будет полностью загружен и проверен по SHA-256.
- Пока приложение открыто, каталог перепроверяется примерно раз в минуту. При обнаружении новой версии просмотр блокируется до синхронизации.
- После успешной синхронизации фотографии и описания сохраняются локально и могут просматриваться офлайн в течение текущего сеанса.
- Для нового запуска нужна сеть, чтобы приложение могло проверить, не опубликована ли обязательная новая версия. Без проверки нельзя гарантировать, что локальная база актуальна.

## Как администратору опубликовать новую базу
1. В приложении открой «Администратор» и добавь или обнови блоки с фотографиями.
2. Выбери «Экспортировать пакет .lineup». Он будет сохранён как community.lineup.
3. Открой репозиторий GitHub, перейди в content/packs/ и загрузи или замени community.lineup.
4. Дождись успешного запуска workflow Publish content catalog. Он вычислит SHA-256 и увеличит обязательный номер версии, только если состав пакетов действительно изменился.
5. Все подключённые приложения увидят новую версию и потребуют обновить базу перед продолжением просмотра.

## Как скачать последнюю тестовую сборку
Открой вкладку Actions, выбери успешный запуск Build Android APK и скачай artifact lineup-debug-apk. Внутри ZIP находится тестовый APK.

## Сборка вручную
Нужны JDK 17, Android SDK Platform 35 и Gradle 8.9:
~~~sh
gradle assembleDebug
~~~
Выходной файл: app/build/outputs/apk/debug/app-debug.apk.

## Публикация
Для RuStore подготовь релизную сборку и собственный ключ подписи; debug APK предназначен только для тестирования. Подключение реальной рекламы пока не включено — перед этим нужно выбрать рекламную платформу и создать рекламный блок.
