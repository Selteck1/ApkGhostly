# ApkGhostly

Тестовый Android-клиент Ghostly + локальный backend.

## Как работает APK

1. Полноэкранный Ghostly intro — 15 секунд.
2. Приложение выполняет реальный запрос к:
   `http://127.0.0.1:8081/api/health`
3. Если сервер отвечает `ok=true`, приложение показывает:
   - ✅ Сервер подключён
   - ✅ Соединение установлено
   - ✅ Система готова к работе
4. Если сервер не отвечает, показывается ошибка и кнопка «Повторить».

## Запуск сервера в Termux

```bash
cd ~/ApkGhostly
bash server/start_server.sh
```

Проверка:

```bash
curl http://127.0.0.1:8081/api/health
```

После запуска сервера установи APK на тот же Android-телефон. Оба процесса смогут обращаться к локальному адресу `127.0.0.1:8081`.

## Важно

Текущий backend — фундамент для настоящего Ghostly API. На следующем этапе сюда можно добавить авторизацию, пользователей, анкеты, поиск, профили, Premium, сообщения и админ-панель.

GitHub Actions автоматически собирает debug APK.
