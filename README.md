# Kemtiz

Kemtiz — ранний тестовый мессенджер, сейчас основной клиент разрабатывается **для Android**. В нём есть вход через Google, профили, поиск пользователей, заявки в друзья, личные и групповые чаты, история сообщений и realtime-обмен через WebSocket.

## Скачать Android APK

В разделе [GitHub Releases](https://github.com/Selteck1/ApkGhostly/releases) выбирай последний релиз с названием `Kemtiz Android preview #...` и тегом `kemtiz-android-...`. Скачивай `Kemtiz-Android.apk`; рядом лежит `Android-OAuth-SHA1.txt` с отпечатком подписи APK для настройки Android OAuth в Google Cloud.

Сборки пока тестовые. До установки обновления поверх старой версии не удаляй предыдущий APK, если в нём есть нужные данные приложения. Новые релизы используют выделенный ключ подписи CI; после проверки стабильности подписи можно безопаснее обновляться между версиями.

## Первый запуск и общий сервер

Для работы из разных сетей телефон подключается к одному общему API по HTTPS. Сам сервер и база данных ещё не создаются автоматически: инструкция развёртывания находится в [kemtiz/DEPLOY.md](kemtiz/DEPLOY.md). В репозитории уже есть конфигурация [Render Blueprint](render.yaml) и поддержка PostgreSQL.

После развёртывания введи полученный HTTPS-адрес на первом экране Kemtiz через кнопку **«Адрес общего сервера»**. Все телефоны должны использовать один адрес, чтобы видеть одинаковые аккаунты, друзей и сообщения.

## Локальная разработка в Termux

Для разработки локальный backend можно запустить на Android через Termux:

```sh
pkg update
pkg install python
python -m pip install -r kemtiz/requirements.txt
cd kemtiz
uvicorn server:app --host 127.0.0.1 --port 8000
```

Локальная SQLite-база хранится в `kemtiz/data/`. Она отдельная от облачной PostgreSQL и сама по себе не переносится в облако. Не добавляй файл базы или секреты в GitHub.

## Backend и безопасность

- FastAPI + SQLite для локальной разработки; PostgreSQL для общего сервера.
- ID-токены Google проверяются сервером через HTTPS.
- Поддерживаются профили пользователей, друзья, личные/групповые чаты и WebSocket.
- Сессии подписываются `KEMTIZ_SECRET`; на хостинге он генерируется автоматически.
- Это ранняя тестовая версия: сквозного шифрования сообщений, полноценного восстановления аккаунта и полного набора антиспам-защит пока нет. Не используй её для чувствительной переписки.

## Автоматические проверки
