# Lineup — конструктор раскидок Standoff 2

В репозитории два Android-приложения:

- **Lineup Admin** — редактор под пароль. Создаёт блоки, хранит фотографии, сохраняет базу локально и готовит команды публикации для Termux.
- **Lineup для игроков** — показывает блоки, описания и фотографии. При запуске получает свежий каталог и пакеты из этого репозитория. Контент можно обновлять без выпуска нового APK.

## Как обновлять блоки без сборки APK

После установки актуальных APK процесс обновления такой:

1. В Lineup Admin добавь или отредактируй блоки, фотографии и нажми **Сохранить**.
2. Нажми **«Обновить блоки без сборки APK»**.
3. В диалоге сохранения выбери папку **Download / Загрузки** и оставь имя `community.lineup`.
4. Приложение покажет готовые команды. Скопируй их кнопкой **«Скопировать обновление»** и вставь в Termux.
5. Команды отправят пакет в GitHub и пересчитают `content/catalog.json`. GitHub Actions обновит каталог, но **не будет собирать APK из-за изменений контента**.
6. Приложение игроков получит новые блоки при следующем запуске или во время проверки каталога. Фото входят в пакет.

### Настройка Termux — только один раз

Кнопка **«Скопировать настройку»** выдаёт команды, которые нужно выполнить один раз:

- установить `git`, `python` и GitHub CLI (`gh);
- разрешить Termux доступ к общим файлам Android;
- пройти `gh auth login` и включить авторизацию Git;
- настроить автора коммитов и клонировать этот репозиторий.

Для отправки изменений требуется войти в свой GitHub-аккаунт в Termux. Секретный токен в APK, Render или отдельном сервере не нужен.

## Telegram-ссылка

В Lineup Admin открой **«Изменить ссылку Telegram»** и сохрани ссылку вида `https://t.me/имя_канала`. Она попадёт в `content/policy.json` при следующем обновлении через Termux.

## Когда всё-таки потребуется новая сборка APK

Сборка нужна только при изменении самого кода приложения — например, при добавлении новых возможностей. Обычное добавление, изменение или удаление блоков и фотографий сборки APK не требует.

Удалённо заблокировать уже установленную старую версию тоже нельзя без аккуратного управления версиями APK: номер версии встроен в приложение. Эта операция отличается от публикации контента.

## Важно при первой установке обновлённого механизма

Текущим установленным APK сначала нужно заменить старый механизм встроенной базы на новый механизм загрузки каталога. После этого обычные обновления блоков будут идти через Termux без пересборки APK. Если Android не разрешит установить тестовую APK поверх прежней из-за различающейся подписи, перед удалением Lineup Admin экспортируй резервную копию `.lineup`, чтобы не потерять локальные блоки и фотографии.
