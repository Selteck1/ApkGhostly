# Kemtiz: сервер на Windows-ПК

Этот комплект запускает Kemtiz API на твоём компьютере вместо Render. Компьютер и интернет должны оставаться включёнными, пока ты хочешь пользоваться перепиской.

## 1. Установи Python

Установи Python 3.12 или новее для Windows: https://www.python.org/downloads/windows/

Во время установки включи Add Python to PATH (если это доступно).

## 2. Запусти сервер

1. Распакуй весь репозиторий либо этот комплект в обычную папку, например `C:\Kemtiz`.
2. Дважды щёлкни `start_kemtiz_server.bat`.
3. При первом старте скрипт создаст виртуальное окружение и установит зависимости. Нужен интернет.
4. Оставь чёрное окно сервера открытым.
5. Проверь на этом компьютере адрес `http://127.0.0.1:8000/health`. После успешного запуска новая версия должна вернуть `api_version: "0.3.0"` и `password_auth: true`.

База аккаунтов и переписки хранится локально в папке `kemtiz-data` рядом со скриптом. Не удаляй эту папку, иначе потеряешь локальные аккаунты и сообщения.

## 3. Открой сервер для телефона через интернет

Чтобы телефон мог подключаться не только в домашней Wi-Fi-сети, запусти во втором окне `start_kemtiz_tunnel.bat`. Скрипт использует Quick Tunnel от Cloudflare, который публикует локальный HTTP-сервер по временной HTTPS-ссылке `trycloudflare.com` без настройки маршрутизатора.

Когда появится строка вида `https://some-words.trycloudflare.com`:

1. Скопируй только адрес HTTPS без пробелов и без дополнительных путей.
2. На телефоне открой Kemtiz Messenger.
3. На экране входа/регистрации найди блок **СВОЙ СЕРВЕР**.
4. Вставь адрес и нажми **Сохранить и проверить сервер**.
5. Дождись сообщения, что новая версия API доступна. После этого регистрируйся или входи.

Запусти серверный .bat первым, туннель — вторым. Оба окна должны оставаться открыты. При остановке туннеля или перезагрузке компьютера временный URL перестанет работать или изменится; в таком случае запусти оба скрипта заново и сохрани новый URL в приложении.

## Безопасность и ограничения

- Quick Tunnel предназначен для тестирования и разработки; его URL временный и любой, кто знает ссылку, может обратиться к API. Не публикуй ссылку в открытом доступе.
- Не выключай защиту Windows и не открывай входящие порты роутера: туннель создаёт исходящее соединение.
- Для постоянного использования потребуется именованный Cloudflare Tunnel с собственным доменом или другой стабильный адрес.
- Если компьютер выключен или спит, сервер и переписка недоступны.
- Не удаляй и не пересылай файлы базы данных и ключа из `kemtiz-data`.

Официальная инструкция Cloudflare Quick Tunnels: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
