# Kemtiz Messenger — сервер на Windows-ПК

Этот комплект запускает API Kemtiz на твоём компьютере. Для первого запуска **не нужен Cloudflare и не нужен HTTPS-туннель** — телефон и ПК должны быть подключены к одной домашней Wi-Fi-сети.

## 1. Установи Python

Нужен Python 3.12 или новее: https://www.python.org/downloads/windows/

Во время установки включи **Add Python to PATH**.

## 2. Запусти сервер

1. Распакуй архив целиком в обычную папку, например `C:\Kemtiz`.
2. Запусти `start_kemtiz_server.bat`.
3. При первом старте скрипт создаст окружение и установит зависимости. Нужен интернет.
4. Если Windows спросит о брандмауэре, разреши Python доступ в **частных сетях**.
5. Оставь чёрное окно сервера открытым.

На компьютере открой `http://127.0.0.1:8000/health`. Должен появиться JSON с `"password_auth": true` и `"api_version": "0.4.0"`.

## 3. Подключи телефон без туннеля

1. На ПК открой командную строку и выполни `ipconfig`.
2. Найди IPv4-адрес адаптера Wi-Fi, например `192.168.1.37`. Не используй адрес `127.0.0.1`.
3. Убедись, что телефон подключён к той же Wi-Fi-сети, что и компьютер.
4. В Kemtiz на экране входа прокрути вниз до **СВОЙ СЕРВЕР**.
5. Введи адрес в формате `http://192.168.1.37:8000` — замени IP на свой.
6. Нажми **Сохранить и проверить сервер**. Если появилось «Сервер Kemtiz доступен. Можно регистрироваться», используй регистрацию по логину и паролю.

Адрес ПК может измениться после перезагрузки роутера. В этом случае снова проверь `ipconfig` и обнови адрес в приложении. На некоторых роутерах включена изоляция клиентов Wi-Fi — тогда телефон не сможет увидеть ПК, даже если они в одной сети.

## 4. Что насчёт доступа из интернета?

Локальный IP работает только в твоей сети. Чтобы друзья подключались из другой сети, серверу нужен общедоступный HTTPS-адрес или частная VPN-сеть, в которой находятся все устройства. Один APK не может сделать домашний сервер доступным из интернета. Не публикуй сервер и не используй HTTP для регистрации через чужую Wi-Fi-сеть.

## 5. Видеозвонки

Видеозвонок доступен в личном чате, когда оба пользователя онлайн и подключены к одному серверу. Сигнализация идёт через Kemtiz, а аудио и видео пытаются передаваться напрямую между устройствами через WebRTC/STUN. В некоторых мобильных сетях и за строгим NAT прямое соединение может не установиться без TURN-релея; пока такой релей не настроен, это ограничение тестовой версии.

## Данные

Аккаунты и сообщения хранятся в папке `kemtiz-data` рядом со скриптом. **Не удаляй эту папку** — там находятся база данных и секрет подписи сессий.
