# Единый сервер Kemtiz (Android + Windows)

Этот вариант нужен для QR-входа через интернет: телефон и ПК должны обращаться к одному API и одной базе PostgreSQL. Клиенты не должны запускать собственные отдельные базы.

## 1. Создать постоянную базу Neon

1. Открой https://neon.tech/ и создай бесплатный PostgreSQL-проект.
2. В панели проекта найди **Connect** и скопируй строку подключения PostgreSQL. Не публикуй её: в ней есть пароль базы.
3. Оставь в строке SSL-параметры, выданные Neon.

Neon хранит аккаунты, друзей, чаты, сообщения и QR-сеансы отдельно от файловой системы хостинга. Это важно, потому что бесплатные веб-сервисы Render используют временную файловую систему.

**Для постоянной базы не выбирай Render Free Postgres:** бесплатные базы Render автоматически истекают через 30 дней. Используй Neon для основной базы; Render в этой конфигурации нужен только для API-сервиса.

## 2. Развернуть API через Render Blueprint

1. Открой https://render.com/ и войди через GitHub.
2. Выбери **New → Blueprint** и подключи репозиторий `Selteck1/ApkGhostly`, ветку `kemtiz-messenger`.
3. Render найдёт `render.yaml` и создаст веб-сервис `kemtiz-api`.
4. При настройке переменных укажи `DATABASE_URL` — строку подключения из Neon. Публичный OAuth Client ID Kemtiz уже прописан в `render.yaml`; отдельный секрет Google не нужен.
5. Для `KEMTIZ_SECRET` Render создаёт случайное значение автоматически. Не меняй его после запуска: оно подписывает сессии входа.
6. Нажми **Apply / Deploy** и дождись успешного развёртывания.

## 3. Проверить сервер

Render покажет публичный URL примерно такого вида: `https://kemtiz-api-....onrender.com`.

Открой `<URL>/health`. Успешный ответ выглядит примерно так:

```json
{"ok":true,"app":"Kemtiz","users":0,"messages":0}
```

Если Google-вход не проходит, проверь, что этот OAuth-клиент настроен в Google Cloud для Kemtiz и что у него разрешён нужный Web/Android OAuth flow.

## 4. Подключить телефон и компьютер

Пока публичный URL не встроен в сборки, укажи **один и тот же HTTPS-адрес** на обоих устройствах:

- **Windows:** открой Kemtiz → **Настроить сервер** → вставь URL Render → перезапусти приложение.
- **Android:** на экране подключения нажми **Адрес сервера** → вставь тот же URL. Если экран входа уже открылся, настройки сервера доступны через экран ошибки/подключения.

После этого ПК создаст QR-сеанс на общем сервере. Телефон, уже вошедший через Google, сканирует QR-код и показывает запрос подтверждения. ПК завершает вход только после подтверждения на телефоне.

## Ограничения бесплатного запуска

- Бесплатный Render Web Service засыпает после периода бездействия. Первый запрос после сна может занять около минуты; для постоянно мгновенного подключения нужен постоянно работающий тариф.
- Бесплатная база Neon имеет ограничения бесплатного плана, но не пропадает при обычном перезапуске веб-сервиса Render.
- Это ранняя версия мессенджера, а не готовый сервис для чувствительной переписки: сквозного шифрования, восстановления аккаунта и полного набора антиспам-защит пока нет.
- Не публикуй строку `DATABASE_URL`, `KEMTIZ_SECRET` или другие секретные значения в GitHub и не встраивай их в EXE/APK.
