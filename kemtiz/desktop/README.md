# Kemtiz для Windows и Android

## Что скачивать

- **Kemtiz-Setup.exe** — установщик. Устанавливает приложение в папку пользователя и предлагает создать ярлык на рабочем столе.
- **Kemtiz.exe** — портативная версия без установки.
- **Kemtiz-Android-LAN.apk** — Android-приложение с Google-входом и встроенным сканером QR-кодов.

## Как работает вход по QR-коду

1. Запусти Kemtiz на ПК. Приложение показывает QR-код, который действует 3 минуты.
2. Подключи Android-приложение к тому же серверу, на котором открыт QR-код.
3. На телефоне войди через Google, нажми **«Подключить компьютер»**, отсканируй QR-код и нажми **«Разрешить вход»**.
4. ПК автоматически завершит вход. QR-код одноразовый; отклонённый, использованный или просроченный код нельзя применить повторно.

На ПК не нужно вводить пароль Google. Подтверждение происходит только в уже авторизованном аккаунте на телефоне.

## Локальный режим для проверки в одной Wi-Fi сети

По умолчанию Kemtiz.exe запускает свой сервер на ПК (порт 8000). Адрес вида `http://192.168.x.x:8000` отображается на экране входа.

1. Подключи ПК и телефон к одной доверенной Wi-Fi сети.
2. Если сервер Kemtiz на телефоне запущен в Termux, останови его сочетанием **Ctrl+C**, чтобы APK показал экран подключения к серверу.
3. В Android-приложении нажми **«Адрес сервера»** и введи адрес, который показан на ПК, например `http://192.168.1.20:8000`.
4. Повтори подключение и войди в Google на телефоне. Затем нажми «Подключить компьютер» и подтверди QR-запрос.
5. Если телефон не подключается, проверь разрешение для Kemtiz в брандмауэре Windows и то, что оба устройства в одной локальной сети.

**Важно:** локальный режим предназначен для проверки. Он хранит базу данных на ПК в `%APPDATA%\Kemtiz\data`. Данные из отдельной базы Termux автоматически не переносятся. Для общего аккаунта через интернет оба клиента должны быть подключены к одному и тому же серверу по HTTPS.

## Подключение к общему серверу

В Kemtiz для Windows нажми **«Настроить сервер»** и укажи полный адрес общего сервера, например `https://kemtiz.example.com`. На Android укажи этот же адрес в настройке сервера. Перезапусти Kemtiz на ПК после изменения адреса.

Публичный сервер и домен этим установщиком не создаются. Для постоянной работы из разных сетей нужен отдельно развернутый HTTPS-сервер с общей постоянной базой данных. Не выставляй порт 8000 напрямую в интернет и не используй HTTP для публичных сетей.

## Данные и безопасность

- Токен входа на ПК хранится в пользовательских настройках Windows; локальная база и секрет подписи сервера сохраняются вне файла EXE.
- Секрет опроса QR-сеанса не попадает в QR-код. Без него нельзя завершить вход на ПК.
- Подтверждай только те QR-коды, которые сам открыл на своём компьютере.
- Предпросмотр остаётся тестовой версией. В нём пока нет сквозного шифрования сообщений и полноценного восстановления аккаунта.

## Сборка из исходников

Сборка выполняется автоматически GitHub Actions из ветки `kemtiz-messenger`. Для ручной сборки Windows-приложения с Python 3.12 выполни из корня репозитория:

    python -m pip install -r kemtiz/requirements.txt -r kemtiz/desktop/requirements.txt
    python kemtiz/desktop/make_icon.py
    python -m PyInstaller --noconfirm --clean --onefile --windowed --name Kemtiz --icon kemtiz/desktop/kemtiz.ico --paths kemtiz --add-data "kemtiz/server.py;." --add-data "kemtiz/web;web" --collect-all PySide6 --collect-all shiboken6 --collect-submodules uvicorn --hidden-import server kemtiz/desktop/launcher.py

Чтобы собрать установщик, дополнительно установи Inno Setup 6 и выполни:

    iscc kemtiz/desktop/installer.iss
