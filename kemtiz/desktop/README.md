# Kemtiz для Windows и Android

## Что скачивать

- **Kemtiz-Setup.exe** — установщик Windows. Устанавливает программу и создаёт ярлык на рабочем столе.
- **Kemtiz.exe** — портативный Windows-клиент без установки.
- **Kemtiz-Android-LAN.apk** — Android-приложение с Google-входом и встроенным сканером QR-кодов.

## Единый сервер

Windows-клиент является только клиентом: в EXE не включены backend, база данных или ключи общего сервера. Сервер и постоянная база разворачиваются отдельно, а программа подключается к ним по HTTPS.

При первом запуске Kemtiz на Windows попросит адрес общего сервера, например `https://kemtiz-api-....onrender.com`. Этот адрес появится после развёртывания по инструкции [kemtiz/DEPLOY.md](../DEPLOY.md). Сохранённый адрес хранится в настройках пользователя Windows, не внутри EXE.

## Вход по QR-коду

1. Запусти Kemtiz на ПК и укажи адрес общего сервера, если это первый запуск.
2. На экране появится QR-код на 3 минуты.
3. На телефоне войди через Google и подключи приложение к **тому же HTTPS-серверу**.
4. Нажми «Подключить компьютер», отсканируй QR и внимательно проверь запрос.
5. Нажми «Разрешить вход». Только после подтверждения Kemtiz на ПК завершит вход.

QR-код сам по себе не предоставляет доступ. Для завершения входа используется отдельный секрет опроса, который остаётся в клиенте ПК и не содержится в QR-данных. Использованный, отклонённый или просроченный код нельзя применить повторно.

## Как развернуть сервер

1. Создай бесплатный проект PostgreSQL в [Neon](https://neon.tech/).
2. Подключи репозиторий `Selteck1/ApkGhostly`, ветку `kemtiz-messenger`, в [Render](https://render.com/) через **New → Blueprint**.
3. При развёртывании добавь `DATABASE_URL` из Neon и `KEMTIZ_GOOGLE_CLIENT_ID` — веб-клиент Google OAuth, который уже использует Kemtiz.
4. После развёртывания проверь `<адрес-сервера>/health`, затем укажи выданный HTTPS-адрес и на ПК, и в Android.

Подробные шаги есть в [kemtiz/DEPLOY.md](../DEPLOY.md). Не отправляй другим людям строку подключения Neon, секрет подписи сессий или другие секреты.

## Локальный запуск backend для разработки

Локальный backend остаётся доступен для разработки и тестирования из исходников. Из корня репозитория:

```sh
python -m pip install -r kemtiz/requirements.txt
cd kemtiz
uvicorn server:app --host 127.0.0.1 --port 8000
```

Для подключения разработческого клиента к локальному серверу можно использовать `http://localhost:8000`. Публичные соединения должны работать по HTTPS. Не выставляй порт 8000 напрямую в интернет.

## Ограничения ранней версии

Это тестовый мессенджер: в нём пока нет сквозного шифрования сообщений, полноценного восстановления аккаунта и полного набора средств защиты от спама. Не используй его для чувствительной переписки.
