# Kemtiz Messenger

Kemtiz — Android-мессенджер с регистрацией по логину и паролю.

## Возможности

- регистрация и вход по username/password;
- поиск пользователей и заявки в друзья;
- личные и групповые чаты;
- история текстовых сообщений и live-обновления через WebSocket;
- видеозвонки один-на-один через WebRTC (тестовая реализация).

## Запуск собственного сервера

- Запусти `start_kemtiz_server.bat` на Windows.
- Для первого тестирования настрой APK на `http://<PC-LAN-IP>:8000`, когда ПК и телефон в одной Wi-Fi-сети.
- Для работы из других сетей настрой доступный публичный HTTPS-адрес или приватную VPN-сеть. Локальный IP не доступен из публичного интернета.

## Видеозвонки

Kemtiz использует WebRTC SDK для Android. WebSocket Kemtiz передаёт приглашения, SDP и ICE-сигналы; аудио/видео пытаются идти напрямую между устройствами, с публичным STUN-сервером. В некоторых сетях необходим TURN-релей, который не входит в этот тестовый пакет.

## Важное ограничение безопасности

Это альфа-версия, а не готовый защищённый production-мессенджер. Режим HTTP разрешён для локального тестирования; не используй его в чужих или публичных сетях. Для доступа из интернета нужен HTTPS. Сквозное шифрование сообщений, надёжные push-уведомления, отправка файлов и постоянно доступный TURN-релей ещё не реализованы.
