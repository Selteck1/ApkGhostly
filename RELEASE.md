# Подготовка Lineup к RuStore

## Перед публикацией
- Проверь работу в авиарежиме.
- Добавь 3–10 скриншотов, иконку 512 × 512, краткое и подробное описание.
- Укажи контакты разработчика и ссылку на политику конфиденциальности.
- Используй только изображения, которые разрешено распространять.
- При подключении рекламы задекларируй SDK и связанные сборы данных согласно правилам выбранного сервиса и магазина.

## Ключ подписи
Создай ключ один раз:
~~~sh
keytool -genkeypair -v -keystore lineup-release.jks -alias lineup -keyalg RSA -keysize 2048 -validity 10000
~~~
Сохрани файл keystore и пароль в безопасном месте. Не загружай keystore в GitHub. Не пересоздавай его между релизами: магазин проверяет совпадение подписи.

Для release-сборки задай переменные окружения:
- LINEUP_KEYSTORE_PATH
- LINEUP_KEYSTORE_PASSWORD
- LINEUP_KEY_ALIAS
- LINEUP_KEY_PASSWORD

Затем запусти команду gradle assembleRelease. Если переменные не заданы, APK будет без настроенной release-подписи — такой файл нельзя загружать как релиз.

## Ненавязчивая реклама
Рекомендуемая схема: один небольшой баннер на главном экране/списке, без полноэкранной рекламы при открытии раскидки и без таймера, прерывающего просмотр. Сейчас показ выключен: требуется выбрать провайдера, создать рекламный блок, получить ID и подключить официальный SDK.
