# Релиз Lineup

## Два приложения
- Lineup Admin — личный редактор контента.
- Lineup — пользовательский APK со встроенными материалами.

## Подпись для стабильных обновлений
Нельзя каждый раз создавать новый ключ: Android не установит новую версию поверх приложения, подписанного другим ключом.

1. Создай lineup-release.jks на своём компьютере с JDK.
2. Сохрани keystore отдельно и создай четыре GitHub Actions secrets: LINEUP_KEYSTORE_BASE64, LINEUP_KEYSTORE_PASSWORD, LINEUP_KEY_ALIAS, LINEUP_KEY_PASSWORD.
3. После публикации базы workflow Build Lineup user APK соберёт подписанный APK и опубликует Lineup-Client.apk в GitHub Releases.
4. Если секреты подписи не заданы, workflow делает только debug-сборку в Actions artifact — для постоянных обновлений это не годится.

## Проверка старой версии
При запуске клиент проверяет удалённую политику. Когда minClientRevision превышает ревизию, встроенную в APK, просмотр блокируется и остаётся кнопка открытия Telegram-ссылки. Блоки и фото встроены в APK, поэтому после успешной проверки они доступны без интернет-запросов.

Строгая удалённая блокировка несовместима с запуском совершенно офлайн: без соединения APK не узнает, что администратор заблокировал старую версию.
